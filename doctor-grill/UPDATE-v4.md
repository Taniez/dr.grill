# อัปเดตหน้าสั่งอาหารและแจ้งคิว

ชุดอัปเดตนี้เปลี่ยนเฉพาะ src/main.js, src/shop-pages.js และเพิ่ม src/refresh.css, src/queue-alerts.js ไม่ต้องรัน SQL หรือ seed ฐานข้อมูลซ้ำ

1. แตก doctor-grill-v4-update.zip จะได้โฟลเดอร์ doctor-grill
2. คัดลอกไฟล์ภายในไปทับโฟลเดอร์ doctor-grill เดิมใน repository ที่เชื่อม Render (ตำแหน่งที่มี package.json) อย่าสร้าง doctor-grill ซ้อนกันอีกชั้น
3. เปิด PowerShell ที่ repository แล้วรัน:

```powershell
git add doctor-grill/src doctor-grill/UPDATE-v4.md
git commit -m "Update orange theme, menu customization and queue alerts"
git push origin main
```

ถ้า Terminal อยู่ภายใน doctor-grill อยู่แล้ว ให้ใช้ `git add src UPDATE-v4.md` แทนบรรทัด git add ข้างต้น

Render ใช้ Root Directory doctor-grill, Build Command `npm ci --include=dev && npm run build`, Start Command `npm start` ตามเดิม เมื่อ Auto-Deploy ทำงาน รอ deployment ล่าสุดขึ้น Live แล้วรีเฟรชเว็บ

## พฤติกรรมใหม่

- ฟอนต์ Noto Sans Thai ผ่าน Google Fonts พร้อมฟอนต์สำรองเมื่อโหลดไม่ได้ และใช้ส้มเป็นสีหลัก
- หน้าแรกปุ่มเมนูอาหาร รวมจัดจานเข้ากับหน้าเมนูและรายละเอียด หน้า cooking เดิมส่งต่อไปยังหน้าใหม่
- เรียงราคาเพิ่ม/ลด ชื่อภาษาไทย หรือกลับลำดับแนะนำ ใช้ร่วมกับค้นหาและหมวดได้
- ขนาดธรรมดา/พิเศษพร้อมราคา เพิ่มไข่ดาว ไข่เจียว เพิ่มข้าวหรือกับข้าวได้ในรายละเอียดอาหาร
- ของเพิ่มคิดจำนวนแยกจากจำนวนจาน แสดงเป็นบรรทัดแยกในตะกร้าและใบสั่ง ไม่ผูกท็อปปิงกับแต่ละจานในฐานข้อมูล หากสั่งหลายเมนูระบุการจัดวางในหมายเหตุหน้า checkout
- ตะกร้ารูปไอคอนลอยมุมขวาล่างทั้งมือถือและคอมพิวเตอร์
- หน้าคิวต้องกดเปิดเสียงก่อน มีเสียงทดลองหนึ่งครั้ง ตรวจสถานะทุก 15 วินาทีและแจ้งหนึ่งครั้งต่อใบสั่งต่อการเปิดหน้านี้ เมื่อพร้อมเสิร์ฟ เฉพาะออเดอร์ที่มี token ในเบราว์เซอร์นี้
- ต้องเปิดหน้าคิวไว้ การปิดแท็บ ล็อกหน้าจอ หรือเบราว์เซอร์พักการทำงานอาจทำให้แจ้งล่าช้าหรือไม่ได้ การสั่นขึ้นกับอุปกรณ์และเบราว์เซอร์ คอมพิวเตอร์ใช้เสียง ไม่มีระบบ push เมื่อปิดเว็บ

## ตรวจสอบ

Build ผ่าน, API/ฐานข้อมูล/ราคา 10 tests ผ่าน (SQLite), ทดสอบ Chrome headless: เรียงราคา เลือกพิเศษ+ไข่เจียว ตะกร้า checkout สถานะพร้อมเสิร์ฟแจ้งเตือน เปลี่ยนทาง cooking และขนาดมือถือ 390px ไม่มี JavaScript error
ยังไม่ได้อัปโหลดขึ้น repository หรือ deploy ชุดนี้ และไม่ได้ทดสอบการสั่นกับโทรศัพท์จริง
