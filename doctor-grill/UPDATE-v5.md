# รูปเมนูและรับออเดอร์หลังบ้าน

ชุดนี้รวมการแก้ไข v4/v4.1 ด้วย คัดลอกโฟลเดอร์ doctor-grill จาก ZIP ทับโฟลเดอร์ชื่อเดียวกันใน repository เดิม ไม่มี .env หรือข้อมูลออเดอร์ใน ZIP ไม่ต้องรัน SQL หรือ seed ใหม่

## นำขึ้น Render

จากราก repository (โฟลเดอร์ที่มี doctor-grill อยู่ภายใน):

```powershell
git add doctor-grill/src doctor-grill/server doctor-grill/public doctor-grill/tests doctor-grill/vite.config.js doctor-grill/staff-order.html doctor-grill/UPDATE-v5.md
git commit -m "Add menu photos and staff order entry"
git push origin main
```

ถ้า Terminal อยู่ภายใน doctor-grill ให้ตัด doctor-grill/ ออกจากคำสั่ง git add

รอ Render deployment ล่าสุดขึ้น Live ใช้ Build Command `npm ci --include=dev && npm run build` และ Start Command `npm start` ตามเดิม

## รูปภาพ

- รูปผู้ใช้ 16 ไฟล์ มีซ้ำ 2 คู่ ใช้รูปไม่ซ้ำ 14 รูปครบและแปลง WebP
- เมนูเดิม 44 รายการมีรูปครบ โดยบางเมนูใช้ภาพร่วมตามประเภทอาหาร เช่นภาพไก่ย่างประกอบเมนูไก่ หรือภาพรวมของทอดประกอบลูกชิ้นที่ยังไม่มีรูปตรงชนิด ไม่มีการอ้างว่าเป็นรูปตรงเมนูทุกภาพ
- เพิ่มภาพเว็บ 6 รูปสำหรับไข่เจียว ไข่ดาว ข้าว ลูกชิ้นทอด ปูอัดทอดและลูกชิ้นปลา มีที่มา ผู้สร้างและใบอนุญาตที่ /photo-credits.html
- API เติมรูปเริ่มต้นให้เมนูที่ไม่มีรูปใน TiDB โดยไม่เขียนทับราคา/ชื่อ/สถานะหรือรูปที่ผู้ดูแลตั้งไว้แล้ว

## รับออเดอร์

เข้าสู่ระบบหลังร้านแล้วเลือก **รับออเดอร์** หรือเปิด /staff-order.html เลือกอาหาร ขนาด และของเพิ่ม ระบุโต๊ะหรือชื่อลูกค้าแล้วส่งเข้าครัว มีตะกร้าแยกจากลูกค้า ราคาและความพร้อมขายตรวจซ้ำที่เซิร์ฟเวอร์ บันทึก event ผู้สร้างเป็น staff มีการป้องกันการส่งซ้ำด้วย requestKey

จำนวน 0 ลบรายการออกจากตะกร้าพนักงาน เมื่อส่งสำเร็จตะกร้าและข้อมูลลูกค้าจะล้างเพื่อรับคนถัดไป พร้อมแสดงใบสั่งที่สร้างแล้ว คำสั่งที่ยังไม่ส่งอยู่ในหน้านี้เท่านั้น อย่ารีโหลดหรือออกจากหน้าก่อนส่ง

ทดสอบ build 16 หน้า, tests 11 รายการ, UI login/สิทธิ์ API, รูปทุกเมนูโหลดได้, รับออเดอร์พิเศษ+ไข่ดาว 90 บาทเข้าครัว, ซ่อนงานเสร็จและดูย้อนหลัง ผ่านบน SQLite/Chrome headless ยังไม่ได้ push หรือ deploy ชุดนี้ และไม่ได้ทดสอบ TiDB Cloud จริงในรอบนี้
